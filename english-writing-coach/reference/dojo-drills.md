# Writing Dojo Drills

Load when the user asks for writing exercises, or when the Recurring-Weakness Loop prescribes a drill for a habitual miss. Assign ONE drill per session; review the result against the rubric item it trains and nothing else.

| Drill | Procedure | Trains |
|---|---|---|
| **Chastity** (Le Guin) | A descriptive page with zero adjectives and adverbs. | C3 |
| **Short and Long** (Le Guin) | One sentence of ≥100 words, then one of ≤7 words; both must read aloud cleanly. | C2, A6 |
| **One-page rewrite** (Zinsser) | 500 words → 250 with no information lost. | B |
| **Nominalization purge** | One paragraph of the user's own academic prose; every -tion/-ment unpacked to verb + agent. | A1–A2 |
| **Stress-position rewrite** | Five sentences restructured so the key word lands last. | A4 |
| **Stress census** (Gopen & Swan) | One long sentence: list every stress-worthy candidate, count the stress positions, restructure until the counts match — split, add a semicolon closure, or demote a candidate. | A4, D3 |
| **Verb inventory** (Gopen & Swan) | List a paragraph's main verbs in a column; for each be-/light verb, name the action it hides — or establish that the action is absent and write it. | A2 |
| **Gap hunt** (Gopen & Swan) | In one paragraph, find the sentence carrying no old information; write the connecting sentence the reader needed. | A3, E5 |
| **Given-new reordering** | Five consecutive sentences re-ordered old → new. | A3 |
| **Punctuation transplant** (Truss) | Strip a passage of all punctuation; re-punctuate from scratch; justify each mark. | D |
| **Problem-statement template** (Booth) | "Although [current state], [gap], which means [cost]" — iterate until each slot is concrete. | F3 |
| **Reader-role** | Explain your result in 3 sentences to (a) an expert supervisor, (b) an adjacent-field colleague, (c) a distant specialist; observe what framing changes. | F1 |
| **Backwards read** (Dreyer) | Read one page sentence-by-sentence in reverse order; mark sentences that fail in isolation (unclear antecedents). | copyediting eye |
| **48-hour stranger** (Bell) | Shelve the piece, change font and margins, read once marking only reactions (confused / bored / lost); no edits on the first pass. | E |
| **Kill the darling** (Bell) | Remove your single favorite sentence; if the piece survives, leave it out. | B, E6 |
